FAQ

Register data is stored in this browser's IndexedDB on this device; there is no automatic cloud backup. Multi-PC Sync sends records to connected peers, and WhatsApp, speech recognition and external libraries use their respective services. Back up regularly — clearing browser data will erase local data.

The QR encodes a compact, offline tracking snapshot directly as a data URL. It shows the status as it was when the QR was created; it does not update after status changes. No internet or server is needed to view the snapshot.

Live scanning needs HTTPS or localhost + camera permission + Chromium browser. If any is missing, use Manual Code Entry — it accepts USB scanner input and typed codes.

Yes. It uses the browser's Web Speech API which does cloud recognition in Chrome/Edge. Requires HTTPS + microphone permission.

Uses WebRTC (PeerJS). One PC hosts, the other connects with the Peer ID. A signalling service is required, and restrictive networks may route traffic through a relay.
